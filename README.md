# solmara-toaster-error

One line for make.fun's "The Funniest Toaster Error Message" bounty: the bread has achieved sentience and refuses to toast. `main.py` prints the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
